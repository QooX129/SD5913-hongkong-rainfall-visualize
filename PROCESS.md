# Process

Step 1: decide which phenomenon and time range I want to show, and further communicate with Copilot to confirm that the data I want is possible to obtain. 

Step 2: ask Copilot to change the data fetching path and update the graph plotting logic.

Step 3: implement Streamlit to create a user interface.

Step 4: come up with a comparison between years idea, tell Copilot to implement it for me.

Step 5: Finally, check everything and add opacity and color for a better user experience.
